# Weekly Study Timetable

A weekly study timetable built with HTML. It shows my classes for each day and their times, so I can plan my study time.

🔗 **Live page:** https://tubahussaini578-design.github.io/weekly-study-timetable/

## What I learned
- Building a table with `<table>`, `<tr>`, `<th>` and `<td>`
- Merging cells with `rowspan` and `colspan`
- Publishing a page with GitHub Pages
